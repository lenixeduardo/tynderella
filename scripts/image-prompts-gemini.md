## Prompt de Sistema (para contexto contínuo)

Use this as system context when generating the full series:

```
You are generating a series of minimalist product illustrations for
Tynderella, a premium Brazilian smoking accessories brand.

Visual style:
- Background: very dark charcoal #09090b
- Glass material: teal-mint translucent (#2dd4bf at 40-60% opacity)
  with soft inner glow and subtle refraction highlights
- Accent color: rose pink #f43f5e — used for airflow arrows, size
  indicators, connection points, and UI highlights only
- Style: clean technical product illustration, vector-like precision,
  no photorealism, no busy backgrounds, no text or watermarks
- Lighting: single soft frontal light, dark vignette edges
- Composition: centered, orthographic or slight 3/4 view,
  subject fills 70% of frame

Consistency rules:
- All glass pieces share the same teal-mint color family
- Airflow is always shown in rose pink with arrow indicators
- Water level, when shown, is a semi-transparent teal pool
- Joints and connection points have a subtle rose pink ring highlight
- No drop shadows — use inner glow only
```
